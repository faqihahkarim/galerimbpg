# Galeri Seramik Pasir Gudang Booking & Management System

A web-based system designed to streamline booking operations for educational and group visits at Galeri Seramik Pasir Gudang.

This platform allows schools and organizations to book activity sessions through an interactive calendar interface, while enabling administrators to manage booking slots, participant allocation, and inventory efficiently.

## Key Features

## Booking System
- Calendar-based slot selection with real-time availability status
- Exclusive slot booking (one group per session)
- Activity-based participant allocation within each booking
- Validation based on activity capacity constraints

## Activity Management
- Multiple activities per session (e.g., coloring, drawing, clay shaping)
- Configurable participant limits per activity
- Automatic validation to ensure total allocation matches group size

## Admin Dashboard
- Manage booking slots by date and time
- Configure activity capacities per session
- Monitor booking requests and approval status
- Inventory management for ceramic products

## User Experience
- Clean, intuitive UI for both users and administrators
- Structured forms with guided validation
- Responsive design for accessibility

## Purpose

This system is built to replace manual booking processes with a structured digital solution, improving operational efficiency, reducing scheduling conflicts, and enhancing the visitor experience.

## Tech Stack
- Frontend: HTML, CSS, JavaScript 
- Backend: Node.js / Laravel 
- Database: MySQL
